# 分发台 · 老师账号连接 0.3.0

与桌面0.5.0-alpha.1配套的开发测试版。每位老师使用一份独立Chrome个人资料，在该资料内连接自己的抖音账号。当前只识别账号和检查连接，不上传视频、不设置封面、不发布作品。

## 首次连接

1. 在工作台“账号与模板”添加老师，再在该老师名下添加抖音账号记录。旧备注可以明确迁入某位老师，不会自动认领登录号。
2. 在该老师的Chrome个人资料中安装本目录扩展。开发版本通过chrome://extensions加载含manifest.json的目录；安装或权限扩大由使用者明确确认。不同老师分别安装在各自资料，不用无痕窗口代替资料。
3. 在工作台对应账号行点“连接账号”。打开扩展，点“打开老师账号连接器”；首次点击“允许连接抖音创作者站点”。这允许程序读取该创作者站点，不能继承旧版只读探针的一次授权。
4. 在连接器输入工作台显示的端口和一次性码。连接器会新开创作者首页；若未登录，由本人登录，再重新识别。只从页面可见的“抖音号”取得身份，读不到唯一号码就停止，不使用手填号码冒充验证。
5. 回工作台核对“实际识别的抖音号”和老师归属，点击“确认绑定到某老师”。确认之前只显示候选，不算绑定。一次性码随即清除，不保存。
6. 保持连接窗口打开，可以最小化。之后在工作台点“检查身份”或“打开账号”，程序只会向已绑定的独立环境发指令；错号会显示阻止，不自动改发到当前前台标签。

## 数据与边界

- 扩展本地保存环境连接标识与本机连接凭据，不使用Chrome同步存储；桌面连接凭据使用操作系统安全存储加密，独立于业务库和导出报告。网站Cookie、密码和浏览器存储不读取、不导出。
- 仅连接127.0.0.1的48717–48726端口；仅按需授权https://creator.douyin.com/*，不申请全站、Cookie、调试器、历史或定位权限；禁止无痕模式共用连接。
- 本版本没有后台服务或系统自启动；账号连接窗口关闭后，工作台会在心跳超时后显示离线。重启工作台保留绑定，连接器仍打开且端口可用时可凭已有连接恢复；端口变化或凭据撤销时需重新连接。
- “停止本窗口连接”停止该窗口并清除其本机凭据，不退出抖音。工作台“解除绑定”撤销对应绑定并保留历史，不退出网站、不删除账号。
- 已绑定、连接在线、身份核对一致是不同状态，均不表示自动发布已完成。其他平台尚未接通。
- 旧版只读探针保留在扩展弹窗的诊断折叠区；不用于真实账号身份核验。

尚待真实Chrome两个账号验收；本地模拟测试不能代替该项验收。Windows包尚未真机测试，当前Mac包只含M系列版本。
